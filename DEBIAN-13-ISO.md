# Debian 13 ISO Reference — Acer R11 Kiosk

For my Acer Chromebook R11 kiosk, I installed **Debian GNU/Linux 13 (Trixie), 64-bit (`amd64`)** with the **XFCE desktop environment**, after changing its firmware using MrChromebox.

## Official Debian downloads

- [Debian 13 installation ISO images](https://www.debian.org/releases/trixie/debian-installer/)
- [Debian 13 installation guide (64-bit)](https://www.debian.org/releases/trixie/amd64/index.en.html)

**Important:** My saved kiosk configuration confirms Debian 13, the 64-bit architecture, and XFCE. It does **not** show the exact installer ISO filename or point release that I originally used. The official download link provides the same Debian major release, not a verified copy of my original installation ISO.

The actual ISO is not included in this package or GitHub repository.
