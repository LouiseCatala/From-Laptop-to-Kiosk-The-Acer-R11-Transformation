
# Acer Chromebook R11 — CAD Design

### From Laptop to Kiosk: The Acer R11 Transformation

This laptop was turned into a kiosk due to limited financial resources, as a kiosk is needed for my thesis. Instead of buying a new one, I reused an Acer Chromebook R11 and modified it into a functional touchscreen kiosk to save money.

## 1. Original Laptop

The Acer Chromebook R11 (CB5-132T-C9KK) was selected as the main hardware for the kiosk conversion.

![Acer Chromebook R11](R11%20laptop.png)

## 2. Dismantled Parts

The laptop was dismantled to reuse its internal components, including the motherboard, battery, speakers, and touchscreen display.

![Dismantled Parts](Dismantled%20Parts.png)

## 3. Assembled Parts

This layout shows how the dismantled components are arranged at the back of the LCD touchscreen.

![Assembled Parts](Assembled%20Parts.png)

## 4. Fully Assembled Kiosk

The final design shows the Acer Chromebook R11 converted into a touchscreen kiosk with a customized enclosure.

![Fully Assembled Kiosk](Fully%20Assembled%20Kiosk.png)

## 5. AutoCAD Design

The kiosk was designed using AutoCAD to visualize the arrangement of the internal components and the complete kiosk structure.

**CAD File:** [Laptop to kiosk.dwg](Laptop%20to%20kiosk.dwg)

## Hardware Components

- **Laptop:** Acer Chromebook R11 (CB5-132T-C9KK)
- **Motherboard:** Quanta ZHR (CYAN)
- **Battery:** AC15A3J
- **Display:** 11.6-inch LCD Touchscreen
- **Speakers:** Internal Stereo Speakers

## Project Purpose

The purpose of this project is to create a cost-effective touchscreen kiosk by repurposing an existing laptop instead of purchasing new hardware.
