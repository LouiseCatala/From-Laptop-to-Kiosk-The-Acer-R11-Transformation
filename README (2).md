# KAWING-Phone Onboard Layout

Files copied from the kiosk's **November 10, 2026** Onboard configuration backup, including a customized phone-style keyboard with character, numeric, emoji and symbols layers.

- `KAWING-Phone.onboard`: Onboard layout configuration
- `KAWING-Phone-Alpha.svg`: alphabet layout drawing
- `Phone-Numbers.svg`, `Phone-Syms.svg`, `Phone-Emoji.svg`: additional layers
- `onboard-settings.ini`: stored desktop preferences (dock, theme, auto-show)

Archived path: `~/.local/share/onboard/layouts/`. Install/configure Onboard separately on Debian; simply copying these files may not reproduce all auto-show behavior.
