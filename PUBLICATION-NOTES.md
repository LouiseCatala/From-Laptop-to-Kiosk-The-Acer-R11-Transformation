# Publication Notes for This Archive

- Created from the user's `KIOSK CONFIGURATION.zip` snapshot, dated **November 10, 2026**.
- Includes real script, keyboard and desktop configuration files; private local IP addresses in the kiosk launcher were replaced with nonfunctional `.example` hostnames.
- Excludes large raw scans/logs and any device-specific dumps, keys or browser profiles.
